# Bilai Weather App

A responsive weather dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Current conditions and temperature
- City search using Open-Meteo geocoding
- Browser location support (permission required)
- Hourly forecast and 5-day outlook
- Humidity, wind, feels-like temperature, UV index, pressure and visibility
- Celsius/Fahrenheit switch and dark/light theme
- Responsive layout for phones, tablets and desktop

## Run locally
Open `index.html` in a browser. For best results, use a local development server (for example VS Code Live Server), especially for browser geolocation.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` (and this README).
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Save and open the published Pages URL.

## Weather data
Uses the public Open-Meteo Forecast and Geocoding APIs. No API key is required. Weather data is provided by Open-Meteo.
